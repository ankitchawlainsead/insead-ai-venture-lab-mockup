Compatibility status

This is a static prototype, not a Drupal theme, import package or published CMS page. Every page body section has a candidate using installed component types. Component existence and selected field lists were checked; exact variants and pixel-level rendering still need validation on a draft page. No new module is proposed.

What is included

  • Homepage: introduction, Sprint feature, research, founder highlights, partner selection, the full source team in an expandable area, five priority FAQs and involvement routes.
  • Sprint 2027 detail: benefits, phased journey, eligibility, key dates, priority FAQs and applications.
  • Past programmes: two programme cards; links retain the existing detailed programme pages.
  • Partnerships: contribution routes, partner selection and contact.
  • Review-only component toggle: identifies the proposed Drupal container for every major section. This toolbar and its script are not production page requirements.

Editorial choices and source coverage

The copy is rewritten for the INSEAD setting. Founder descriptions paraphrase source testimonials rather than presenting new direct quotes. The homepage highlights three founders, eight of the twelve source partners and five priority FAQs. The remaining testimonials, full FAQ bank, advisor list, press coverage, hub narrative and impact figures remain in the source inventory for an editorial migration decision; they are not silently treated as migrated.

  • Impact: source static HTML exposed zero-valued animated counters. No impact numbers were invented. The past-programme card’s 500+ founders and 70+ countries comes from the separate past-programmes page.
  • Dates: the Sprint page lists 27 January–2 April 2027, with an application deadline of 1 December 2026 at 11:59 pm GMT+8. Recheck status when this goes live. The homepage’s “register your interest” wording was resolved using the dated Sprint page.
  • 2027 prize: no cash amount appears in the concept because the current source says it will be announced.
  • Photography: the hero is labelled as the 2025 Sprint. The featured portrait is labelled as a past participant. Do not imply that either depicts the 2027 cohort.
  • People: names and shortened roles follow the source. Reconfirm titles with the Lab before publishing. Do not create duplicate Person records.
  • External applications: all three role applications continue to venture-lab.ai/apply/…. No form, tracking or submission storage is reproduced. Confirm form ownership and approved data wording before changing the application journey.
  • Source disclaimer: the source explicitly describes independent website operation. It was not transplanted as if it were INSEAD.edu policy. This prototype instead carries a clear review notice. Replace that notice with the approved institutional footer and any required form notice in the CMS implementation.

Build in the CMS

  1. Open the assigned unpublished Landing page and choose Layout. Use the existing Body region.
  2. For body content choose Custom block → Create inline block, give it a meaningful title and untick Display title. Add a layout component first: normally Section, with the appropriate content component inside.
  3. Use native component variants, columns, backgrounds and image crops. Follow the fallback in the table when the exact concept styling is unavailable. Do not paste the full prototype HTML, stylesheet or script into Drupal.
  4. Prepare hidden content in a Section with Administrative Title: Draft Content, set Header → Section Title, and untick Published. Avoid Reusable unless sharing is specifically intended and cleared with the web team.
  5. Paste copy as plain text into the appropriate fields; keep rich-text editing in Full HTML. Copy semantic text, lists and links only.
  6. Use existing Media Library items where appropriate. Handbook minimums: banner 1920×410, webcard 1280×720, person 370×370; images under 1 MB. The source portraits for Thomas Baker (345×345) and Alexander Chia (312×393) are below the 370×370 handbook minimum and need better masters. See the asset dimension audit. Do not upscale and call them compliant. Use descriptive alternative text.
  7. Use relative paths for internal INSEAD links and the same window; absolute URLs and new windows for external sources. Point the local menu at approved aliases.
  8. Save in order: editing frame Save, block Update, page Save Layout. Keep the work unpublished for review. Do not use Discard changes or Rebuild layout as routine exit controls.

Design basis

Primary green #00684B, deep green #003837, pale green #E9F4EA, black body copy; Roboto body and Roboto Slab light headings. These follow the supplied 2026 INSEAD brand guide (typography pp. 19–21; green palette pp. 24–25 as printed). Existing theme typography wins where its implementation differs. The prototype’s precise spacing, crop, banner composition and card borders are visual guidance.
