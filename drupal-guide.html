What changed

  • Standard full-width image banner replaced the split hero.
  • Native sans-serif web typography replaced the large Roboto Slab campaign headings.
  • Native pale local navigation and the actual INSEAD header/footer structure replaced the extra Lab identity strip and custom navigation bar.
  • Existing white panels, card borders, curved media corners, green bases, circular Profile Cards and accordion separators are retained.
  • Dates, benefits and programme phases use ordinary text and lists. Partners use a text listing. No new timeline, fact-strip or logo-grid design is required.

Implementation boundary

native.css packages the public INSEAD styles without changing their visual declarations; referenced icon files are embedded for portability. The source record identifies every stylesheet. preview.css contains review controls, guide formatting and small adapters for navigation/accordion interaction in the static preview. Neither stylesheet should be pasted into Drupal.

Inside Drupal, assemble these components with the existing theme and current editor options. Use the centrally managed header, footer and local menu. Use existing Person and Media records where possible. The preview’s CSS image crop stands in for Drupal’s generated 16:9 image derivative; choose the matching media crop in the CMS.

Before putting the draft live

  • Confirm the final INSEAD location and aliases; the HTML filenames here are preview destinations.
  • Recheck programme status and dates. The source currently gives 27 January–2 April 2027 and a 1 December 2026, 11:59 pm Singapore-time application deadline.
  • Confirm the approved application destination and operator notice. The current forms remain independently operated on Venture Lab.
  • Use better portrait masters for Thomas Baker (345×345) and Alexander Chia (312×393): both source files fall below the handbook’s 370×370 person minimum. Asset dimension audit.
  • Select the equivalent existing Variants in the draft and review the result. Matching rendered classes does not by itself prove an editor’s permissions or menu options.

CMS assembly

  1. Open the assigned Landing page using Layout.
  2. Use the existing Body region; add Custom block → Create inline block, turn off Display title, add a Section, then the content component.
  3. For unpublished preparation use Administrative Title: Draft Content, Header → Section Title, with Published unticked.
  4. Paste text without imported styling into Full HTML. Internal links use relative paths and the same window; external links use absolute URLs and a new window.
  5. Save frame Save, block Update, then Save Layout. Keep the draft unpublished for review.
